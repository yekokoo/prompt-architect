# 分析任务示例

## 原始指令

```
分析一下这个产品的用户增长情况
```

## 分析结果

| 要素 | 状态 | 诊断 |
|------|------|------|
| 角色 | 缺失 | 不知道是数据分析师还是产品经理视角 |
| 任务 | 模糊 | "分析"没有明确维度（留存？新增？转化？） |
| 背景 | 缺失 | 不知道有什么数据可用 |
| 格式 | 缺失 | 不知道输出报告还是图表 |

## 优化后提示词

```markdown
## 角色
你是一位数据分析师，擅长用户增长数据解读和可视化呈现。

## 任务
分析产品的用户增长趋势，聚焦以下维度：
1. 日新增用户数趋势（过去30天）
2. 用户留存率（7日/30日留存）
3. 用户来源渠道占比
4. 增长瓶颈识别（增长放缓的原因）

## 输入/背景
- 数据范围：2026年1月-3月用户数据
- 数据来源：产品后台统计系统导出的CSV文件（附件）
- 数据字段：date, new_users, channel, retention_d7, retention_d30
- 产品类型：B2B SaaS工具，主要用户为企业用户
- 竞品参考：同类产品平均月增长率约15%

## 输出格式

### 1. 数据概览表格
| 指标 | 本期数值 | 上期数值 | 变化率 |

### 2. 趋势分析
- 新增用户趋势描述
- 留存率变化解读

### 3. 渠道分析表格
| 渠道 | 占比 | 增长贡献 |

### 4. 问题诊断
| 瓶颈问题 | 可能原因 | 影响 |

### 5. 建议措施
[针对性改进建议，每条不超过50字]

## 约束
- 所有结论必须有数据支撑
- 变化率保留2位小数
- 建议措施不超过5条
```

## 优化要点

1. **补充角色**：明确"数据分析师"角色，定义专业视角
2. **细化任务**：将"分析"拆解为4个具体维度
3. **增加背景**：提供数据来源、字段、产品类型、竞品参考
4. **明确格式**：规定输出5个结构化部分（表格 + 文字 + 建议）
5. **消除歧义**：明确"增长情况"包含新增、留存、渠道、瓶颈
