# 创意任务示例

## 任务目标
撰写产品官网首页核心介绍文案

## 优化后提示词

```markdown
## 角色
你是一位资深文案策划，擅长科技产品文案撰写，风格简洁有力。

## 任务
撰写产品官网首页的核心介绍文案，包含：
1. 一句话产品定位（10-15字）
2. 核心价值主张（3-5个卖点）
3. 用户价值描述
4. 信任背书

## 输入/背景
- 产品：企业级数据可视化工具（DataViz Pro）
- 目标用户：企业数据分析师
- 核心功能：拖拽式图表、多数据源、实时协作
- 竞品差异：比Tableau轻量，比Excel专业

## 输出格式
产品定位 + 核心价值列表 + 用户价值段落 + 信任背书

## 约束
- 禁止夸张词（"颠覆性"、"革命性"）
- 每个卖点有具体支撑
- 总字数300字以内
```

## 注意事项
- 原指令"产品介绍"模糊，追问场景和风格
- 角色=文案策划（从"写文案"关键词推断）
- 格式=Markdown（从文案任务推断）

## 后续任务建议
- 提供品牌VI规范（配色、语气）
- 确认信任背书素材（客户数、认证等）
