# 创意任务示例

## 原始指令

```
帮我写一个产品介绍文案
```

## 分析结果

| 要素 | 状态 | 诊断 |
|------|------|------|
| 角色 | 缺失 | 不知道是文案策划还是销售视角 |
| 任务 | 模糊 | "产品介绍"没有明确场景（官网？广告？邮件？） |
| 背景 | 缺失 | 不知道产品是什么、卖点是什么 |
| 格式 | 缺失 | 不知道输出短文案还是长文章 |

## 优化后提示词

```markdown
## 角色
你是一位资深文案策划，擅长科技产品文案撰写，风格简洁有力。

## 任务
撰写产品官网首页的核心介绍文案，包含：
1. 一句话产品定位（10-15字）
2. 核心价值主张（3-5个关键卖点，每个15-20字）
3. 用户价值描述（目标用户 + 使用场景 + 解决问题）
4. 信任背书（适合放入的认证/客户/数据）

## 输入/背景
- 产品：一款企业级数据可视化工具（DataViz Pro）
- 目标用户：企业数据分析师、运营团队
- 核心功能：拖拽式图表制作、多数据源对接、实时协作
- 竞品差异：比Tableau轻量，比Excel专业，上手时间约30分钟
- 风格偏好：商务简洁，避免夸张营销词，多用数据说话

## 输出格式

## 产品定位
[一句话定位]

## 核心价值
- [卖点1]
- [卖点2]
- [卖点3]

## 用户价值
[目标用户] + [使用场景] + [解决问题]

## 信任背书
[可选背书点，如：服务客户数、行业认证等]

## 约束
- 禁止使用"颠覆性"、"革命性"等夸张词
- 每个卖点必须有具体支撑（功能或数据）
- 文案总字数控制在300字以内
- 使用口语化表达，避免生僻词
```

## 优化要点

1. **补充角色**：明确"文案策划"角色，定义写作风格
2. **细化任务**：将"产品介绍"拆解为4个具体部分
3. **增加背景**：提供产品信息、目标用户、竞品差异、风格偏好
4. **明确格式**：规定输出结构（定位 + 价值 + 用户价值 + 背书）
5. **消除歧义**：明确"产品介绍"用于官网首页，风格商务简洁
