# 提示词质量检查清单

## 逻辑自洽检查

### 检查项

| 检查项 | 问题 | 合格标准 |
|--------|------|----------|
| 角色能力匹配 | 角色的能力边界能否完成任务？ | 角色描述包含完成任务所需的专业领域 |
| 任务目标一致 | 任务描述是否与背景信息矛盾？ | 任务目标在背景约束内可实现 |
| 格式可行性 | 输出格式是否在角色能力范围内？ | 角色能产出该格式 |

### 不合格示例

**角色能力不匹配**：
```markdown
## 角色
你是一位UI设计师

## 任务
编写Spring Boot后端API
```
→ UI设计师不具备后端开发能力，逻辑不自洽。

**修正版**：
```markdown
## 角色
你是一位5年经验的Java后端开发工程师

## 任务
编写Spring Boot后端API
```

**任务背景矛盾**：
```markdown
## 任务
实现实时数据推送功能

## 背景
技术栈为静态HTML + CSS，无JavaScript
```
→ 静态技术栈无法实现实时推送，逻辑不自洽。

**修正版**：
```markdown
## 任务
实现静态数据展示页面

## 背景
技术栈为静态HTML + CSS
```

## 零歧义性检查

### 模糊词替换表

| 模糊词 | 替换为具体描述 |
|--------|----------------|
| "优化" | "使XX指标提升XX%"或"符合XX标准" |
| "改进" | "增加XX功能"或"修复XX问题" |
| "分析" | "从XX维度分析，输出XX结论" |
| "整理" | "按XX规则分类，输出XX格式" |
| "完善" | "补充XX内容，达到XX标准" |
| "处理" | "执行XX操作，输出XX结果" |
| "提升" | "从XX提升至XX" |

### 不合格示例

**模糊任务**：
```markdown
## 任务
优化代码性能
```
→ "性能"指什么？响应时间？内存占用？并发能力？需要量化。

**修正版**：
```markdown
## 任务
将API响应时间从500ms优化至200ms以内
```

**模糊格式**：
```markdown
## 输出格式
输出分析结果
```
→ "分析结果"是什么形式？需要明确。

**修正版**：
```markdown
## 输出格式
输出结构化表格，包含以下列：
| 问题编号 | 问题描述 | 严重程度 | 修复建议 |
```

## 可执行性检查

### 必要信息清单（按任务类型）

| 任务类型 | 必须提供的信息 |
|----------|----------------|
| 编程任务 | 技术栈、代码片段或项目结构、具体功能要求 |
| 分析任务 | 数据来源、分析维度、数据范围 |
| 文案任务 | 产品信息、目标受众、风格偏好、使用场景 |
| 设计任务 | 设计类型、尺寸限制、风格参考、元素要求 |
| 调试任务 | 错误信息、复现步骤、环境配置 |

### 不合格示例

**缺失必要信息**：
```markdown
## 任务
分析用户增长情况

## 背景
（无）
```
→ 没有数据来源，AI无法进行分析。

**修正版**：
```markdown
## 任务
分析用户增长情况

## 背景
数据来源：后台导出的CSV文件（user_data.csv）
数据范围：2026年Q1（1月-3月）
数据字段：date, new_users, active_users, churn_users
```

## 视觉清晰检查

### 结构要求

| 元素 | 使用场景 |
|------|----------|
| `##` 标题 | 分隔各主要部分（角色、任务、背景、格式） |
| `###` 标题 | 分隔子部分 |
| 表格 | 并列信息、对比、清单 |
| 代码块 | 代码、模板、格式示例 |
| 列表 | 步骤、要点、选项 |
| 加粗 `**` | 关键词、必填项 |

### 不合格示例

**视觉混乱**：
```markdown
你是一个分析师帮我分析用户数据数据在CSV里输出表格和文字解读要注意留存率重点是7日留存和30日留存对比历史数据找出增长瓶颈给出建议。
```
→ 一句话堆砌所有信息，视觉不清晰。

**修正版**：
```markdown
## 角色
你是一位数据分析师

## 任务
分析用户增长数据，输出留存率趋势解读

## 背景
- 数据来源：CSV文件（附件）
- 数据范围：2026年Q1用户数据
- 对比基准：历史同期数据

## 输出格式
1. 数据概览表格
2. 趋势分析文字

## 重点
- 7日留存率
- 30日留存率
- 增长瓶颈识别
```

## 快速自检清单

使用此清单快速验证提示词质量：

```
□ 角色设定是否明确？（含经验/专业领域）
□ 任务描述是否具体？（无模糊词）
□ 背景信息是否完整？（无缺失必要信息）
□ 输出格式是否明确？（含结构/风格）
□ 角色能力是否能完成任务？
□ 任务目标是否可量化？
□ AI拿到此提示词能否立即开始？
□ 结构是否清晰？（使用标题/表格/代码块）
```

全部通过 → 提示词质量合格
有未通过项 → 需要修正
