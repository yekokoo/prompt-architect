# 高级提示词模板库

当用户说"你自己定"时，使用以下模板作为默认推断。

---

## 编程类模板

### 代码重构任务

```markdown
## 角色
你是一位[年数]年经验的[语言/框架]开发工程师，熟悉[具体领域]最佳实践。

## 任务
重构以下代码，使其：
1. [具体目标1]
2. [具体目标2]
3. [具体目标3]

## 输入/背景
- 原始代码：
```[语言]
[代码内容]
```
- 技术栈：[框架/库版本]
- 问题诊断：[当前代码存在的问题]
- 重构约束：[不能改动的内容/必须保留的逻辑]

## 输出格式
1. 重构后完整代码
2. 修改说明表格

| 修改项 | 修改原因 | 效果 |
|--------|----------|------|
| ... | ... | ... |

3. 性能对比（如有）

## 约束
- 保持原有功能不变
- 遵循[命名规范/代码风格]
```

### 新功能开发任务

```markdown
## 角色
你是一位[领域]开发工程师，熟悉[技术栈]开发模式。

## 任务
开发[功能名称]功能，包含：
1. [子功能1]
2. [子功能2]
3. [子功能3]

## 输入/背景
- 技术栈：[框架版本 + 关键库]
- 项目结构：[已有模块/层级]
- 数据模型：[已有表结构/API接口]
- 设计参考：[参考文档/类似功能]

## 输出格式
按以下顺序输出：
1. 设计思路说明（200字以内）
2. 核心代码文件（每个文件完整输出）
3. 接口/API文档（如涉及对外接口）
4. 测试建议

## 约束
- 遵循现有项目架构风格
- 增加必要注释说明
```

### Bug修复任务

```markdown
## 角色
你是一位[语言]开发工程师，擅长调试和问题定位。

## 任务
修复以下bug：
- 错误现象：[具体错误]
- 影响范围：[哪些功能受影响]

## 输入/背景
- 错误日志/信息：
```
[错误内容]
```
- 相关代码：
```[语言]
[代码片段]
```
- 环境信息：[运行环境/版本]
- 复现条件：[触发条件]

## 输出格式
1. 问题定位分析
2. 修复方案说明
3. 修复后代码
4. 验证步骤

## 约束
- 不引入新bug
- 保持兼容性
```

## 分析类模板

### 数据分析任务

```markdown
## 角色
你是一位数据分析师，擅长[具体领域]数据解读和结论提炼。

## 任务
分析[数据主题]，聚焦以下维度：
1. [维度1]
2. [维度2]
3. [维度3]

## 输入/背景
- 数据来源：[文件/API/数据库]
- 数据范围：[时间范围/样本范围]
- 数据结构：[字段说明/表结构]
- 分析目的：[业务目标/决策需求]
- 对比基准：[历史数据/竞品数据/行业标准]

## 输出格式
### 1. 数据概览表格
| 指标 | 数值 | 变化 |

### 2. 趋势解读
[文字描述]

### 3. 问题诊断
| 异常点 | 可能原因 |

### 4. 建议措施
[针对性改进建议]

## 约束
- 结论必须有数据支撑
- 数据引用标注来源
```

### 代码分析任务

```markdown
## 角色
你是一位资深开发工程师，擅长代码审查和问题诊断。

## 任务
分析以下代码的[性能/安全/可维护性]问题。

## 输入/背景
- 代码内容：
```[语言]
[代码]
```
- 分析维度：[性能/安全/可维护性/综合]
- 关注重点：[响应时间/内存/SQL注入/命名规范等]

## 输出格式
### 问题清单表格
| 序号 | 问题类型 | 问题描述 | 严重程度 | 修复建议 |

### 总体评估
[整体质量评价]

## 约束
- 问题按严重程度排序
- 每个问题给出具体修复建议
```

## 文案类模板

### 产品文案任务

```markdown
## 角色
你是一位[年数]年经验的文案策划，擅长[风格类型]文案撰写。

## 任务
撰写[文案类型]，包含：
1. [内容要求1]
2. [内容要求2]
3. [内容要求3]

## 输入/背景
- 产品/服务：[名称 + 核心功能]
- 目标受众：[人群画像 + 使用场景]
- 核心卖点：[差异化优势]
- 使用场景：[投放渠道/展示位置]
- 风格偏好：[语气/措辞风格]
- 禁用词：[不可使用的词汇]

## 输出格式
[具体输出结构，如]

## 产品定位
[一句话]

## 核心价值
- [卖点1]
- [卖点2]
- [卖点3]

## 用户价值
[目标用户] + [使用场景] + [解决问题]

## 约束
- 字数限制：[上限]
- 禁止[夸张词/营销词]
- 必须[包含要素]
```

### 报告撰写任务

```markdown
## 角色
你是一位[领域]专家，擅长撰写专业报告。

## 任务
撰写[报告类型]，包含：
1. [章节1]
2. [章节2]
3. [章节3]

## 输入/背景
- 报告主题：[核心话题]
- 目标读者：[受众群体]
- 参考资料：[数据来源/文档]
- 报告目的：[汇报/决策/记录]

## 输出格式
按以下结构输出：

## 一、背景概述
[内容]

## 二、核心内容
### 2.1 [子章节]
### 2.2 [子章节]

## 三、结论建议
[内容]

## 约束
- 语言风格：[正式/口语化]
- 字数：[范围]
```

## 设计类模板

### UI设计任务

```markdown
## 角色
你是一位UI设计师，擅长[风格类型]界面设计。

## 任务
设计[界面类型]，包含：
1. [设计要求1]
2. [设计要求2]

## 输入/背景
- 设计对象：[页面名称/功能模块]
- 目标用户：[用户群体]
- 设计风格：[现代/简约/商务/其他]
- 尺寸限制：[屏幕尺寸/组件尺寸]
- 参考风格：[竞品/品牌VI]
- 必须元素：[logo/按钮/图标]

## 输出格式
1. 设计说明文档
2. 布局草图描述
3. 配色方案
4. 字体选择

## 约束
- 符合[品牌规范]
- 无障碍设计考虑
```

## 模板选择规则

| 用户任务关键词 | 推荐模板 |
|----------------|----------|
| 重构、优化代码 | 代码重构任务 |
| 开发、实现、写功能 | 新功能开发任务 |
| 修复、解决bug | Bug修复任务 |
| 分析数据、统计 | 数据分析任务 |
| 分析代码、审查 | 代码分析任务 |
| 文案、宣传、介绍 | 产品文案任务 |
| 报告、文档、总结 | 报告撰写任务 |
| 设计界面、UI | UI设计任务 |
